JeuVoice — the voice editor: which layout fits your team?

Both screens do the same jobs: fix a word, retake a part, export. They differ in what the user looks at first.

A

Script first (paragraph cards)

The script is the main view. Each paragraph is one card with its own audio. Click a word to respell it, or retake the whole card with new seeds. This matches how tr2 renders today (paragraph mode).

B

Timeline first (one waveform)

The whole voice-over is one long waveform, with the words under it (from Whisper). Drag over a region to select it, then retake only that region. Feels like an audio editor.
