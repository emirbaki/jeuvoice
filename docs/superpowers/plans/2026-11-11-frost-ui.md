# Frost UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give JeuVoice the Frost glass look, a tile board for the Train tab, smooth tab and tile motion, and a wave colored by sound pitch.

**Architecture:** A new `style` module holds every color, panel, button kind and motion value. Each page then moves to it, one page per task. The Train tab gets an `open_tile` state and a board view. The core `Peaks` gets a zero-crossing rate per bucket, and `waveform.rs` colors each column from it.

**Tech Stack:** Rust 2024, rune (pinned rev in `Cargo.toml`), `scripts\cargo.cmd` for every build and test.

**Spec:** `docs/superpowers/specs/2026-11-11-frost-ui-design.md`

## Global Constraints

- Toolkit: rune at the pinned revision. No new UI crate.
- At most 4 blurred elements per screen (`MAX_BACKDROP_BLURS = 4`). Every blurred element has a key that starts with `glass-`. No other element uses `backdrop_blur`.
- Keep every existing element `key`. A test changes only when the behavior stays the same (for example, an extra tap to open a tile).
- Dark only. No light mode. No new user-facing features.
- Frost values (approximate, from the spec): background `#18191d`→`#101114` with a white spot at about 8 % at the top left. Glass fill white about 5.5 %, border white about 9 %, radius about 14 pt. Accent `#ff9f5a`. Secondary text about `#8d8e96`.
- Orange accent only for the main action of a page, the active state and progress. All other buttons are gray glass.
- Board tiles on the Train tab are summaries only: no buttons and no text fields on the board.
- Page change: fade plus about 8 pt upward offset, about 0.2 s.
- Default window: 1100 × 720 points. The Train board shows with no page scroll at that size.
- Each `snap_*` test writes to `target/<name>.png`.
- Prose (comments, commit messages, UI text) follows the ASD-STE100 standing rule.

## Review Focus

1. **Many sources on the Train board:** 12 sources must not overflow the Data tile. The tile shows the first few and "+N more". Test in Task 3.
2. **A small window (900 × 600):** board tiles must not overlap. The page may scroll below the default size. Test in Task 3.
3. **Silence and clipped audio in the wave:** the zero-crossing rate of silence is 0, never NaN, and the color stays defined. Test in Task 5.
4. **Long names in tiles and pills** (an 80-character source name, longer Turkish text after i18n): the text wraps or ends with an ellipsis inside its tile. Test in Task 3.
5. **Overlays on top of a page** (recipe page, word fix, Kaggle form): the screen still has at most 4 `glass-` elements. Test in Task 3 (recipe open) and Task 6 (word fix open).

**Files:**

**Interfaces:**
- Produces:
  - `pub struct Palette { pub bg_top: Color, pub bg_bottom: Color, pub glow: Color, pub glass: Color, pub glass_border: Color, pub highlight: Color, pub text: Color, pub text_secondary: Color, pub accent: Color, pub accent_text: Color, pub red: Color, pub green: Color, pub teal: Color, pub pink: Color }`
  - `pub fn palette() -> Palette`
  - `pub fn red() -> Color`, `pub fn orange() -> Color` (= accent), `pub fn green() -> Color`
  - `pub fn background(child: El) -> El` — full-size page background with the gradient and the glow.
  - `pub fn glass(el: El) -> El` — glass fill, border, top highlight, radius 14, no blur.
  - `pub fn glass_blur(key: &str, el: El) -> El` — `glass` plus `backdrop_blur(18.0)`. Panics in debug builds if `key` does not start with `glass-`.
  - `pub enum ButtonKind { Main, Normal, Quiet }`
  - `pub fn button_kind(key: &str, label: &str, kind: ButtonKind, enabled: bool, on: impl Fn(&mut App, &mut Tx) + 'static) -> El`
  - `pub fn button(key, label, enabled, on) -> El` = `button_kind(.., ButtonKind::Normal, ..)`
  - `pub fn pill(text: &str, color: Color) -> El` — rounded label for totals and diff marks.
  - `pub const PAGE_ENTER: (f32, f32)` = `(0.0, 8.0)` offset for the page transition. `pub fn page_transition() -> Transition`.
  - `pub fn contrast(fg: Color, bg: Color) -> f32` — WCAG contrast ratio from sRGB.
  - `#[cfg(test)] pub fn take_main_keys() -> Vec<String>` — drains a thread-local list. `button_kind(.., ButtonKind::Main, ..)` pushes its key to that list in test builds, so a page test can see which buttons are main buttons.

### Task 5: Wave colored by pitch

**Files:**
- Modify: `crates/jeuvoice-core/src/peaks.rs` (field `zcr: Vec<f32>`, filled in `peaks()`, a `range_zcr` reader)
- Modify: `crates/jeuvoice-app/src/waveform.rs` (`wave_shape` colors, dimming, word gaps, playhead glow)
- Modify: tests that build `Peaks` literally: `crates/jeuvoice-app/src/transcribe_tab_tests.rs:385`, `voice/tests.rs:356`, `waveform.rs:254` (add `zcr: vec![0.0; n]`)
- Test: `crates/jeuvoice-core/tests/peaks.rs`, `crates/jeuvoice-app/src/waveform.rs` (`mod tests`)

**Interfaces:**
- Produces:
  - `Peaks::zcr: Vec<f32>` — zero crossings per sample in the bucket, 0.0 to 1.0. Same length as `min`.
  - `pub fn range_zcr(&self, start_s: f64, end_s: f64, buckets: usize) -> Vec<f32>` — the mean rate per output column, same bucketing as `range`.
  - `pub fn pitch_color(rate: f32) -> Color` in `waveform.rs` — maps the rate to orange (low) → pink (middle) → teal (high), using `style::palette()`. Scale: rate 0.02 or less is pure orange, 0.25 or more is pure teal.
  - `pub const UNPLAYED_ALPHA: f32 = 0.30`.
  - `fn column_color(col: usize, playhead_col: f32, rate: f32) -> Color` — `pitch_color(rate)` with alpha 1.0 before the playhead column and `UNPLAYED_ALPHA` after it. `wave_shape` uses it for each column.
  - `wave_shape(v, peaks, words, width)` gains `words: &[Word]` to leave a 3 pt gap at each word end (only at zoom levels where a word is at least 12 pt wide).

- [ ] **Step 1: Write the failing tests:**
